## BigQuery Graph ya en GA: grafo nativo en BigQuery
Google Cloud anuncia la disponibilidad general de BigQuery Graph, una capacidad nativa de grafo dentro de BigQuery que permite consultas GQL junto a SQL y evita la necesidad de ETL a bases de datos de grafo separadas. La funcionalidad está pensada para casos donde las relaciones entre entidades importan (por ejemplo, trazabilidad de pagos o grafos de entidad) y se integra con BigQuery ML y funciones de IA dentro de las mismas consultas. Además, Google ha publicado varios lanzamientos de producto recientes (incluyendo mejoras en BigQuery continuous queries con procesamiento stateful en preview) para facilitar pipelines de datos y agentes que consumen señales en tiempo real. [Fuente: Google Cloud Blog sobre BigQuery Graph y resumen de novedades]. ([cloud.google.com](https://cloud.google.com/blog/products/data-analytics/bigquery-graph-connecting-data-and-ai-at-scale/?utm_source=openai))

## Microsoft lanza MAI-Transcribe-2: nuevo modelo de transcripción multilingüe
Microsoft presentó MAI-Transcribe-2, un modelo de transcripción que la compañía describe como más rápido, más preciso y con un precio de lanzamiento promocional (USD 0.10 por hora de audio) para la vista previa pública en Azure Speech. Según el anuncio, el modelo cubre decenas de idiomas, ofrece diarización y marcas de tiempo a nivel de palabra, y Microsoft publica comparativas de benchmark en su nota de prensa y canales oficiales. MAI-Transcribe-2 se ofrece inicialmente en modo preview y Microsoft facilita acceso a través de Microsoft Foundry y servicios de Azure Speech. [Fuente: Microsoft / Tech Community]. ([publicnow.com](https://www.publicnow.com/view/CBC6972710EC7D2B9A3663216E38404072AF28B7?utm_source=openai))

## NVIDIA acuerda adquirir Hugging Face por aproximadamente $12.9B
NVIDIA ha anunciado un acuerdo para adquirir Hugging Face en una operación cercana a los 12.93 mil millones de dólares, con la intención declarada de escalar la plataforma y facilitar el acceso a herramientas y modelos abiertos para desarrolladores. La operación fue anunciada públicamente por NVIDIA y aparece en documentos regulatorios presentados por la compañía; los comunicados indican que Hugging Face se integrará manteniendo prácticas abiertas, y la transacción incluye componentes destinados a retención accionaria para empleados. [Fuente: comunicado NVIDIA y presentación SEC]. ([blogs.nvidia.com](https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/?utm_source=openai))

## Gran interrupción / errores elevados en modelos conversacionales (3 Sep)
El 3 de septiembre se detectaron errores elevados y caídas momentáneas que afectaron a varios servicios de modelos conversacionales (entre ellos ChatGPT, Claude y otros), con reportes de usuarios y registros de estado oficiales que muestran incidentes y picos de error durante ventanas de minutos a horas. Las páginas de estado oficiales (OpenAI, Anthropic) y medios de información cubrieron la incidencia; las empresas registraron y mitigaron los eventos, y las investigaciones públicas se centraron en degradaciones de infraestructura y recuperación de servicio. Se recomienda revisar las páginas de estado de cada proveedor si dependes de APIs de modelos para producción. [Fuente: seguimiento de estado y cobertura de medios]. ([status.openai.com](https://status.openai.com/incidents/2rm6gqeh?utm_source=openai))

## Azure y AWS simplifican la interconexión privada multicloud
Microsoft y Amazon Web Services han anunciado colaboración para facilitar la conectividad privada entre Azure y AWS mediante una experiencia de interconexión multicloud gestionada (Azure Multicloud Interconnect + AWS Interconnect - multicloud). El objetivo es reducir la complejidad de establecer conectividad privada de alto rendimiento entre nubes para cargas de trabajo distribuidas y aplicaciones a escala de IA, con enfoque en aprovisionamiento más rápido y menor carga operativa para clientes multicloud. Microsoft y AWS publicaron entradas técnicas y blogs explicando el funcionamiento y el estado de la integración (preview/GA según región/servicio). [Fuente: AWS blog y Microsoft Source]. ([aws.amazon.com](https://aws.amazon.com/blogs/networking-and-content-delivery/aws-and-microsoft-azure-collaborate-to-expand-multicloud-networking/?utm_source=openai))

## Go 1.27.1: parche menor publicado (1 Sep)
El proyecto Go publicó la revisión go1.27.1 el 1 de septiembre; se trata de una versión de parche que incluye correcciones en cgo, el compilador, el runtime y varios paquetes estándar (por ejemplo `database/sql`, `net/http`, `encoding/json`), y está disponible en los canales oficiales de descarga. Microsoft también ha publicado builds de su distribución de Go basadas en 1.27.1 para entornos donde se utiliza el Microsoft build de Go. [Fuente: release history de Go y anuncio Microsoft para builds]. ([go.dev](https://go.dev/doc/devel/release?utm_source=openai))

## Incidente en Google Cloud: degradación en la zona us-central1-b (1 Sep)
Google Cloud registró el 1 de septiembre un incidente de degradación de red que afectó a una porción de la zona `us-central1-b`, provocando errores y pérdida de paquetes para múltiples productos (Compute Engine, GKE, Cloud SQL, BigQuery, Cloud Run, Hybrid Connectivity, entre otros). Google publicó el incidente en su panel de estado con ventanas de inicio/mitigación y recomendaciones de reintentos; varios servicios dependientes se vieron impactados temporalmente. [Fuente: Google Cloud Service Health]. ([status.cloud.google.com](https://status.cloud.google.com/incidents/J5ia5t9p3g9Q5Wi7r8Ev?utm_source=openai))

## NVIDIA en IFA 2026: herramientas para IA local y PAIR (Personal AI Router)
En IFA 2026 NVIDIA presentó anuncios destinados a facilitar la ejecución de modelos y agentes localmente: optimizaciones para inference con `llama.cpp`/vLLM, la herramienta PAIR (Personal AI Router) para repartir inferencia entre PCs en la red local, y la llegada de PCs Windows “RTX Spark” orientados a ejecutar agentes en dispositivos de escritorio/portátiles. Las novedades buscan disminuir la fricción para ejecutar agentes y modelos a escala doméstica o en entornos distribuidos pequeños (p. ej. homelab con varias GPUs). [Fuente: blog técnico de NVIDIA sobre IFA y artículo de desarrolladores]. ([blogs.nvidia.com](https://blogs.nvidia.com/blog/local-ai-ifa-next-gen-agents-nv-pair-rtx-spark/?utm_source=openai))

Es útil para desarrolladores .NET que quieran añadir capacidades RAG a APIs y aplicaciones web sin partir desde cero. [Fuente: blog elmah.io y recopilación .NET Ketchup].
