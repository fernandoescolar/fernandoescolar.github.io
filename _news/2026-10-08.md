## C Dev Kit: versión más rápida y ligera
Microsoft publicó una entrada del blog explicando una reescritura significativa de C# Dev Kit para Visual Studio Code que reduce el uso de memoria y acelera la apertura de soluciones. La nueva arquitectura apunta a abrir soluciones "en torno a un segundo" y a consumir mucha menos memoria en escenarios grandes, con mejoras en la experiencia de edición, IntelliSense y depuración para desarrolladores .NET. Este cambio promueve flujos más ágiles en proyectos C# grandes y equipos que usan VS Code como IDE principal. [Fuente (Microsoft .NET Blog)](https://devblogs.microsoft.com/dotnet/ "A faster, lighter C# Dev Kit"). ([devblogs.microsoft.com](https://devblogs.microsoft.com/dotnet/?utm_source=openai))

## GPT‑6 e Intelligent UI llega a ChatGPT
OpenAI anunció el despliegue de GPT‑6 en ChatGPT junto con "Intelligent UI": la capacidad del asistente para devolver respuestas que combinan texto, elementos visuales e interfaces interactivas (botones, formularios, diagramas) que el usuario puede manipular directamente. El lanzamiento comenzó el 7 de octubre para Plus/Pro/Business/Enterprise y se amplió a Free/Go posteriormente; OpenAI describe mejoras en la latencia de inicio de respuesta y habilita interfaces progresivas que aparecen mientras el modelo continúa pensando. [Fuente (OpenAI)](https://openai.com/index/gpt-6-for-everyone/ "GPT‑6 and Intelligent UI for everyone"). ([openai.com](https://openai.com/index/gpt-6-for-everyone/?utm_source=openai))

## Decisions API de OpenAI entra en beta pública
OpenAI puso en beta pública su Decisions API, que permite obtener respuestas tipadas (decisiones/juzgamientos) de forma muy rápida usando modelos de la familia GPT‑6 (ej. `gpt-6-luna`). La API está diseñada para tareas de clasificación/decisión (aceptar/denegar, seleccionar opción, puntuaciones) con coste explicado en la documentación de desarrolladores; la publicación oficial y el changelog indican la disponibilidad en beta y los detalles iniciales de facturación y modelos soportados. [Fuente (OpenAI API Changelog)](https://developers.openai.com/api/docs/changelog "OpenAI API changelog — Decisions API"). ([developers.openai.com](https://developers.openai.com/api/docs/changelog?mw_entry=2026-08-20-974ac0734e053853&utm_source=openai))

## Acceso para investigadores académicos: OpenAI apoya 100k investigadores
OpenAI publicó recursos y programas para favorecer el uso de ChatGPT y sus modelos en investigación académica: anunciaron un programa de acceso destinado a 100,000 investigadores académicos para facilitar experimentación y descubrimiento científico con sus modelos avanzados, así como materiales de apoyo para uso responsable en entornos de investigación. La iniciativa apunta a acelerar trabajos en múltiples disciplinas con acceso a capacidades de modelado y herramientas de asistencia. [Fuente (OpenAI Research)](https://openai.com/research/index/release/ "OpenAI — Research releases"). ([openai.com](https://openai.com/research/index/release/?utm_source=openai))

## Grok 4.7 disponible en Microsoft Foundry
Microsoft comunicó en su canal de comunidad que Grok 4.7 (de SpaceXAI / xAI) está disponible en Microsoft Foundry Models. La llegada de Grok 4.7 amplía el catálogo de modelos gestionados por Foundry, permitiendo a desarrolladores y empresas seleccionar Grok 4.7 para cargas de trabajo que buscan razonamiento de largo alcance, ingeniería de software y flujos de agentes. La nota oficial del equipo Foundry en la comunidad técnica confirma la disponibilidad y la integración de Grok en el catálogo. [Fuente (Microsoft Foundry / Tech Community)](https://techcommunity.microsoft.com/ "Introducing Grok 4.7 on Microsoft Foundry"). ([techcommunity.microsoft.com](https://techcommunity.microsoft.com/category/azure-ai-foundry/blog/azure-ai-foundry-blog?trk=article-ssr-frontend-pulse_little-text-block&utm_source=openai))

## Gemini 3.5 Transcribe: GA en la plataforma Agent (Google Cloud)
Google Cloud documentó la disponibilidad de Gemini 3.5 Transcribe como modelo de transcripción de audio en Agent Platform (Gemini Enterprise / Agent Studio). La documentación muestra funciones como transcripción en tiempo real (`gemini-3.5-transcribe-live`), detección automática de idioma, diarización de hablantes, marcas de tiempo a nivel de palabra y modos "SMART" para limpieza y formateo inteligente del texto. La página de producto detalla límites y recomendaciones de uso para flujos de trabajo de transcripción en la nube. [Fuente (Google Cloud Docs)](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-5-transcribe "Gemini 3.5 Transcribe — Google Cloud"). ([docs.cloud.google.com](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-5-transcribe?utm_source=openai))
