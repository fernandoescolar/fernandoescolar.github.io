## GKE: Topology Manager llega a GA para cargas sensibles (NUMA)
Google Cloud anuncia que el GKE Topology Manager ya está en estado Generally Available para clústeres que requieren alta consistencia de rendimiento (AI/ML, HPC). El Topology Manager permite alinear CPU, memoria y GPU respecto a la topología NUMA del nodo, reduciendo la latencia por cruce de sockets y mejorando el throughput en cargas sensibles. La gestión y políticas de alineación se configuran a través de la API de NodeConfig, y la funcionalidad está orientada a equipos que necesitan optimizar rendimiento sin reescribir las aplicaciones. ## GKE: Node Memory Swap disponible en vista previa privada
Google Cloud ha publicado la capacidad de configurar swap en disco para nodos estándar de GKE como preview privado. La función permite usar espacio en disco (boot disk o SSD local) como memoria virtual para amortiguar picos de uso y reducir OOM y evicciones de pods en workloads con patrones de memoria impredecibles. Está pensada como red de seguridad, no sustituto de memoria física: requiere versiones mínimas de clúster y tiene requisitos para tipos de máquinas y QoS de pods; además incluye opciones de cifrado y recomendaciones de monitorización. Acceso mediante petición al equipo de cuenta. Fuente: [Documentación GKE Node Memory Swap].  
Fuente: [GKE Node Memory Swap — Google Cloud Docs](https://docs.cloud.google.com/kubernetes-engine/docs/how-to/node-memory-swap)

## GKE: amplia expansión de NodeConfig (más control de sysctl y kubelet)
En la misma tanda de novedades, GKE amplía las opciones de `NodeConfig` con casi 130 nuevas configuraciones de `sysctl` y parámetros de `kubelet`. Esto permite a los operadores aplicar afinamientos de kernel y kubelet de forma nativa (sin DaemonSets complejos), facilitando ajustes de seguridad, rendimiento y compatibilidad a nivel de nodo. La medida simplifica la preparación de nodos para cargas especializadas (bases de datos en memoria, infra para modelos de IA, etc.) y reduce la complejidad operativa al centralizar las opciones en la API de GKE. Fuente: [Google Cloud — What’s new with Google Cloud].  
Fuente: [Google Cloud — What’s new with Google Cloud](https://cloud.google.com/blog/topics/inside-google-cloud/whats-new-google-cloud-2025)
