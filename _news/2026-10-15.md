## .NET 11 Release Candidate 2 disponible
Microsoft publicó .NET 11 Release Candidate 2, una nueva release candidate que incluye mejoras en librerías, runtime, SDK, MSBuild, NuGet, F#, ASP.NET Core, .NET MAUI y otros componentes. El post oficial indica que RC2 cuenta con licencia "go‑live" para uso productivo y enlaza a las notas de la release para ver detalles técnicos y descargas.  
[Fuente: Microsoft .NET Blog](https://devblogs.microsoft.com/dotnet/dotnet-11-rc-2/)

## Parche crítico en GitLab: CVE-2026-97229
GitLab publicó un parche urgente (versiones de parche: 19.4.2, 19.3.5, 19.2.8) que corrige una vulnerabilidad crítica en el compilador de expresiones regulares de CI/CD que, en ciertas condiciones, permitía ejecución remota de código. La recomendación del proveedor es actualizar inmediatamente las instancias autogestionadas y seguir la guía oficial del parche.  
[Fuente: GitLab — Patch release (notas oficiales)](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-4-2-released/?utm_source=feedly)

## Go 1.27 mejora la reutilización de conexiones HTTP/1
El equipo de Go publicó un artículo explicando un cambio en Go 1.27 que mejora la reutilización de conexiones HTTP/1 y reduce la penalización por no leer cuerpos de respuesta, lo que puede acelerar programas que hacen muchas peticiones secuenciales HTTP/1. El post describe el problema histórico y la solución en `net/http`.  
[Fuente: Go Blog](https://go.dev/blog/http-connection-reuse)

## Docker Desktop 4.95: actualización de mantenimiento (octubre 2026)
Docker publicó notas de versión que listan la versión 4.95.0 (publicada en octubre), correcciones de fiabilidad, y actualizaciones de componentes como `containerd` y el motor Docker. Es una actualización relevante para desarrolladores locales y entornos de desktop que usan Docker Desktop.  
[Fuente: Docker Docs — Release Notes](https://docs.docker.com/desktop/release-notes/)

## LFM2.5-24B-A2B: modelo diseñado para agentes privados on‑device
LiquidAI y Hugging Face presentaron LFM2.5-24B-A2B, una variante pensada para ejecutar agentes privados localmente (arquitectura MoE con pocos parámetros activos por token). El artículo explica casos de uso on‑device, opciones de despliegue (weights abiertos en Hugging Face) y recomendaciones para integrar el modelo en flujos de agentes privados.  
[Fuente: Hugging Face Blog — LiquidAI / LFM2.5-24B-A2B](https://huggingface.co/blog/LiquidAI/lfm25-24b-a2b)

## Agentic Resource Discovery (ARD): especificación draft para que agentes busquen herramientas
Hugging Face publicó un post (repositorio del blog) sobre la especificación Agentic Resource Discovery (ARD), un borrador abierto desarrollado con contribuciones de Microsoft, Google y otros. ARD propone un manifiesto (`ai-catalog.json`) y una API REST para que los agentes descubran herramientas, skills y MCP servers de forma federada en tiempo de ejecución. La entrada incluye la implementación de referencia “Discover” en el Hub.  
[Fuente: Hugging Face / GitHub — Agentic Resource Discovery (draft)](https://github.com/huggingface/blog/blob/main/agentic-resource-discovery-launch.md)

## HiRO-ACEv2: emulación de clima a 3 km con coste reducido
AllenAI publicó HiRO-ACEv2 en Hugging Face, un sistema de dos etapas (ACE + HiROv2) que genera salidas climáticas a 3 km y está orientado a simular eventos extremos con coste significativamente menor que modelos numéricos tradicionales. El artículo y el paper indican que HiRO-ACEv2 reproduce estadísticas de eventos extremos con alta fidelidad y ofrece demos y notebooks para investigadores.  
[Fuente: Hugging Face Blog — HiRO-ACEv2 (AllenAI)](https://huggingface.co/blog/allenai/hiro-acev2)

## InfoQ organiza panel sobre RAG y AI en producción (prácticas y riesgos)
InfoQ anunció un panel en el que se debatirán prácticas para ejecutar AI en producción: autonomía de agentes, aprobación humana, verificación de cambios generados por IA, exposición de datos sensibles y consideraciones de RAG en sistemas reales. Es un recurso útil para equipos que operan arquitecturas basadas en retrieval y agentes.  
[Fuente: InfoQ — Retrieval-Augmented Generation / Eventos y noticias](https://www.infoq.com/retrieval-augmented-generation/news/)

## Google DeepMind y Google Cloud donan acceso a modelos y créditos a investigadores europeos
Google DeepMind y Google Cloud anunciaron un programa para proporcionar acceso a modelos frontier y créditos de cómputo a investigadores en Europa (incluye herramientas como AlphaFold 3, WeatherNext, AlphaGenome y otras). El objetivo es facilitar la investigación científica aprovechando modelos y créditos cloud.  
[Fuente: Google Blog / DeepMind — apoyo a investigación científica en Europa (octubre 14, 2026)](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/were-powering-european-scientific-discovery-with-advanced-ai-compute-and-frontier-models/)

## Azure Enclave: GA para entornos aislados y cargas sensibles
Microsoft anunció la disponibilidad general de Azure Enclave, un servicio administrado para crear entornos de trabajo aislados (communities / enclaves) pensado para gobiernos y sectores regulados. Azure Enclave incluye gobernanza, observabilidad y plantillas para colaborar en cargas sensibles con controles y cumplimiento.  
[Fuente: Microsoft Cloud Blog — Azure Enclave (GA, 13 Oct 2026)](https://www.microsoft.com/en-us/microsoft-cloud/blog/us-government/2026/10/13/azure-enclave-is-now-generally-available-managed-workload-isolation-for-government-and-regulated-industries/)
