## Microsoft presenta Maia 300 y expande Azure Maia a multi‑gigavatios
Microsoft anunció Maia 300, la siguiente generación de su sistema de inferencia Azure Maia, y planes para escalar la familia Azure Maia a despliegues de varios gigavatios a partir de 2027.  
El anuncio describe a Maia 300 como una plataforma optimizada para cargas de inferencia a escala que prioriza rendimiento por vatio y tokens por megavatio, con mejoras anunciadas en throughput y eficiencia respecto a generaciones previas.  
Microsoft indica que Maia 200 ya se usa en producción para cargas internas y que Maia 300 se integrará con servicios como Copilot y Microsoft Foundry para mejorar la latencia y el rendimiento de experiencias con agentes y modelos.  
La nota técnica y la cobertura oficial incluyen detalles de arquitectura y el objetivo de convertir Maia en el sistema principal de inferencia para los productos y servicios de Microsoft.  
Fuente: [Microsoft – Official Blog: Microsoft to expand Azure Maia system to multi‑gigawatt deployments (Oct 12, 2026)](https://blogs.microsoft.com/blog/2026/10/12/microsoft-to-expand-azure-maia-system-to-multi-gigawatt-deployments/) ([blogs.microsoft.com](https://blogs.microsoft.com/blog/2026/10/12/microsoft-to-expand-azure-maia-system-to-multi-gigawatt-deployments/?utm_source=openai))

## Google Cloud lanza Data Agent Kit
Google Cloud publicó el Data Agent Kit, un conjunto para crear agentes orientados a datos que facilita conectar agentes a servicios de datos de Google Cloud y orquestar pipelines de análisis y limpieza.  
El kit incluye integraciones y herramientas para que los agentes interactúen con BigQuery, almacenes de datos y flujos ETL, con ejemplos y extensiones para entornos de desarrollo como Antigravity IDE y VS Code.  
La iniciativa enfatiza gobernanza y control sobre accesos y operaciones de los agentes en entornos corporativos, intentando cerrar la brecha entre prototipos generados por LLMs y productos de datos gobernados en producción.  
Fuente: [Google Cloud Blog: Agentic data science with the Data Agent Kit (Oct 12, 2026)](https://cloud.google.com/blog/products/data-analytics/bringing-you-the-data-agent-kit) ([cloud.google.com](https://cloud.google.com/blog/products/data-analytics/bringing-you-the-data-agent-kit?utm_source=openai))

## BigQuery anuncia TimesFM 3.0 para forecasting multivariante
BigQuery presentó TimesFM 3.0, una versión del modelo de forecasting que ahora soporta pronóstico multivariante dentro de SQL en BigQuery.  
TimesFM 3.0 permite condicionar predicciones en múltiples series y covariables (por ejemplo, promociones, calendarios o eventos) sin necesidad de entrenar y desplegar modelos externos; la ejecución se hace directamente con AI.FORECAST en SQL.  
Google señala que TimesFM 3.0 es un modelo de foundation model entrenado para series temporales multivariantes y lo ofrece en vista previa para facilitar forecasting en pipelines analíticos nativos.  
Fuente: [Google Cloud Blog: Introducing TimesFM 3.0 with multivariate time‑series forecasting (Oct 12, 2026)](https://cloud.google.com/blog/products/data-analytics/bigquery-timesfm-3-0-with-multivariate-time-series-forecasting) ([cloud.google.com](https://cloud.google.com/blog/products/data-analytics/bigquery-timesfm-3-0-with-multivariate-time-series-forecasting?utm_source=openai))

## Looker Data Apps: apps de datos gobernadas en Google Cloud
Google Cloud anunció Looker Data Apps, una forma de crear aplicaciones de datos gobernadas que integran seguridad, row‑level access y controles de gobernanza para despliegues de apps impulsadas por datos y agentes.  
La idea es ofrecer un lienzo más controlado y seguro para convertir dashboards y análisis en aplicaciones ejecutables que puedan colaborar con flujos agenticos y respetar políticas corporativas.  
Looker Data Apps busca facilitar que equipos de negocio y tecnológicos publiquen aplicaciones de datos con modelos de acceso y auditoría integrados, reduciendo la fricción al pasar prototipos a entornos productivos.  
Fuente: [Google Cloud Blog: Introducing Looker Data Apps (Oct 12, 2026)](https://cloud.google.com/blog/products/business-intelligence/introducing-looker-data-apps) ([cloud.google.com](https://cloud.google.com/blog/products/business-intelligence/introducing-looker-data-apps?utm_source=openai))

## Google presenta el Gemini agent para trabajo empresarial
Google Cloud sigue desplegando su visión agentica: el Gemini agent fue presentado como un agente universal para el trabajo, capaz de planificar tareas, orquestar sub‑agentes y conectarse a sistemas empresariales con controles de gobernanza.  
El agente puede elegir modelos según la tarea, mantener identidades y registros de auditoría separados para agentes "coworker", y enviar entregables directamente dentro de documentos, bandejas de entrada y herramientas de desarrollo.  
El anuncio se produjo en el evento Gemini at Work y Google ha publicado materiales y casos de uso empresariales; la disponibilidad inicial es por preview privada y con foco en integraciones de Workspace y servicios en Google Cloud.  
Fuente: [Blog de Google: Google Cloud introduces the Gemini agent (Oct 8, 2026)](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/gemini-at-work/) ([blog.google](https://blog.google/innovation-and-ai/infrastructure-and-cloud/google-cloud/gemini-at-work/?utm_source=openai))

## Microsoft Foundry: agentes hospedados con permisos para SharePoint
Microsoft Foundry publicó una guía para construir agentes hospedados que respeten permisos en SharePoint, mostrando patrones para exponer datos internos a agentes sin romper controles de acceso ni gobernanza.  
El artículo explica cómo separar permisos del usuario y los permisos que el agente necesita, estrategias de sandboxing, y prácticas recomendadas para auditar y revocar accesos en escenarios colaborativos de Microsoft 365.  
El enfoque busca facilitar la publicación segura de agentes en Teams y Copilot integrados con fuentes de conocimiento corporativas, minimizando fugas de datos sensibles.

## Mechrevo Master Road X10 y su propuesta de 'AI SSD' para modelos grandes
El fabricante Mechrevo presentó (o mostró) el Master Road X10, un mini PC que propone usar un "AI SSD" para mover partes de modelos grandes desde DRAM a NAND y así soportar modelos de mayor tamaño en memoria limitada.  
Los detalles disponibles son preliminares y la compañía no ha publicado mediciones independientes que verifiquen la eficacia o el rendimiento real de ese enfoque en cargas LLM grandes; la idea apunta a extender la capacidad práctica de mini‑PCs para IA local.  
La propuesta atrae interés por su promesa de ampliar el conjunto de modelos que pueden ejecutarse en factor de forma compacto, pero requiere validación técnica y pruebas en escenarios reales.
