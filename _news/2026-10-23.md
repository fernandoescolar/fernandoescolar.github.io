## Agentic AI Foundation añade cuatro proyectos abiertos
La Agentic AI Foundation (AAIF) anunció el 22 de octubre la incorporación de cuatro proyectos aportados por grandes actores de la industria: Agent Skills (Anthropic), Open Responses (OpenAI), OpenEnv (Hugging Face) y OpenSandbox (Alibaba). Con estas incorporaciones la fundación amplía su cartera de proyectos abiertos para estandarizar componentes del ecosistema de agentes (skills, respuestas interoperables, entornos y sandboxes), buscando facilitar interoperabilidad y gobernanza neutral. El anuncio se hizo público durante AGNTCon + MCPCon North America en San Jose y refuerza la tendencia de mover especificaciones de agentes a gobernanza abierta. ([prnewswire.com](https://www.prnewswire.com/news-releases/agentic-ai-foundation-announces-global-2026-events-program-anchored-by-agntcon--mcpcon-north-america-and-europe-302732860.html?utm_source=openai))  
Fuente: [PR Newswire — Agentic AI Foundation Announces Four New Projects (22 Oct 2026)](https://www.prnewswire.com/news-releases/agentic-ai-foundation-announces-global-2026-events-program-anchored-by-agntcon--mcpcon-north-america-and-europe-302732860.html)

## Google Cloud añade modelos de OpenAI a Model Garden (preview empresarial)
Google Cloud anunció que incorpora modelos de OpenAI en su Model Garden como una vista previa privada para clientes empresariales seleccionados. La integración permite comprar y consumir modelos de OpenAI a través de la facturación de Google Cloud y usar compromisos de gasto existentes; incluye referencias a modelos de frontera citados por Google y menciona integración futura en Antigravity y Gemini para empresas. El movimiento amplía la opción de modelos dentro de una única plataforma cloud para clientes empresariales. ## OpenAI publica Decisions API para decisiones rápidas y baratas
OpenAI presentó el 22 de octubre su Decisions API, un endpoint pensado para tareas de decisión estructurada (clasificación, enrutamiento, respuestas tipo opción) con latencias y coste reducidos respecto a llamadas de generación largas. La API está orientada a aplicaciones que requieren juicios rápidos y determinísticos (p. ej. enrutamiento, clasificación) y soporta entrada mixta (texto, imágenes, JSON de evidencia). OpenAI documenta la disponibilidad del producto y casos de uso en su página de producto. ([openai.com](https://openai.com/index/decisions-api/?utm_source=openai))  
Fuente: [OpenAI — Build more responsive apps with the Decisions API (22 Oct 2026)](https://openai.com/index/decisions-api/)

## Microsoft atribuye ataque ConnectWise a grupo Storm-0940 que usó ARTEX
Microsoft Security publicó el 21 de octubre un informe donde atribuye la reciente compromisión de ConnectWise Cloud Backup a un grupo China‑vinculado que el equipo rastrea como Storm-0940. Según Microsoft, el actor utilizó ARTEX, un framework agentic AI para automatizar reconocimiento, password spraying, abuso de OAuth y otras etapas, impactando a cientos de organizaciones y acelerando operaciones hasta alcanzar acceso privilegiado en casos en menos de tres horas. Microsoft proporciona detecciones y recomendaciones para clientes afectados. ([microsoft.com](https://www.microsoft.com/en-us/security/blog/2026/10/21/storm-0940-uses-artex-agentic-ai-connectwise-supply-chain-compromise/?utm_source=openai))  
Fuente: [Microsoft Security Blog — AI-driven, large-scale nation-state campaign using ARTEX (21 Oct 2026)](https://www.microsoft.com/en-us/security/blog/2026/10/21/storm-0940-uses-artex-agentic-ai-connectwise-supply-chain-compromise/)

## Microsoft expande Project Perception: “Guardian Agents” y control de agentes internos
Microsoft publicó el 19 de octubre un ensayo y novedades sobre Project Perception en el que plantea tratar a los agentes AI desplegados internamente como “insider risks”. La compañía propone controles dinámicos (identidades de agente, permisos mínimos por tarea, cálculo de riesgo dinámico y Guardian Agents que supervisan acciones en tiempo real) y anuncia capacidades en Microsoft 365 E7 para contener y auditar agentes dentro de la empresa. El post describe la necesidad de supervisión continua y trazabilidad para gobernar agentes que tienen acceso a datos y sistemas críticos. ([blogs.microsoft.com](https://blogs.microsoft.com/blog/2026/10/19/securing-the-agentic-insider/))  
Fuente: [Official Microsoft Blog — Securing the agentic insider (19 Oct 2026)](https://blogs.microsoft.com/blog/2026/10/19/securing-the-agentic-insider/)

## Walmart lanza Agent Gateway y Agent Profiles para compras con agentes AI
Walmart anunció el 21 de octubre la creación de “Agent Profiles”, el “Walmart Agent Gateway” y un conjunto de términos para agentes AI que compran en nombre de clientes. Cada agente recibirá un perfil dentro de la cuenta del cliente (con historial separado), controles de gasto y aprobaciones por defecto; el Gateway, en beta para desarrolladores, usará MCP (Model Context Protocol) para permitir que asistentes autorizados busquen y completen compras sin recibir todos los datos personales del cliente. El anuncio busca facilitar agentes de terceros (ChatGPT, Gemini, Muse, etc.) con límites y trazabilidad. ([corporate.walmart.com](https://corporate.walmart.com/news/2026/10/Making-It-Possible-for-Agents-to-Shop-on-Behalf-of-Customers?utm_source=openai))  
Fuente: [Walmart Corporate — Making It Possible for Agents to Shop on Behalf of Customers (21 Oct 2026)](https://corporate.walmart.com/news/2026/10/Making-It-Possible-for-Agents-to-Shop-on-Behalf-of-Customers)

## LiteLLM: versión 1.107.0 comprometida en PyPI y Docker (credential stealer)
El 21 de octubre se informó que la release `litellm==1.107.0` fue publicada a PyPI y a tags oficiales de Docker con artefactos maliciosos. Las ruedas y algunas imágenes contenían un “credential stealer” y un cargador remoto; el equipo de LiteLLM reportó que la canalización de publicación fue comprometida y que las versiones fueron retiradas/quarantined tras la detección. Las investigaciones iniciales apuntan a un repositorio look‑alike usado para generar artefactos. La comunidad recomienda revocar claves expuestas, auditar instalaciones y evitar reinstalar el paquete hasta confirmación oficial. ([docs.litellm.ai](https://docs.litellm.ai/blog/security-incident-oct-21-2026?utm_source=openai))  
Fuente: [LiteLLM — Contained: Oct 21, 2026 LiteLLM release v1.107.0 Compromised (21 Oct 2026)](https://docs.litellm.ai/blog/security-incident-oct-21-2026)

## PHP: parches de emergencia por php2shell (CVE-2026-109618 / CVE-2026-109619)
El 21 de octubre se publicaron parches de seguridad críticos para PHP que corrigen dos vulnerabilidades de ejecución remota (apodadas “php2shell”) identificadas como CVE‑2026‑109618 y CVE‑2026‑109619. PHP lanzó versiones parcheadas (por ejemplo 8.5.12, 8.4.27, 8.3.36, 8.2.35) y múltiples proveedores y proyectos (distros, imágenes Docker, hosts compartidos) están emitiendo actualizaciones y mitigaciones. Dado el carácter de RCE y la rápida explotación observada en ciertos vectores, la recomendación general es actualizar PHP y los contenedores inmediatamente. ([frontiernow.dev](https://frontiernow.dev/en/news/php2shell-php-rce-patch/?utm_source=openai))  
Fuente: [Resumen de parches y contexto — PHP2Shell / parches (21 Oct 2026)](https://frontiernow.dev/en/news/php2shell-php-rce-patch/)

## Actualizaciones y parches en Docker / Compose tras problemas TLS y parches críticos
Tras las incidentes de seguridad en componentes TLS y la llegada de parches críticos (incluido el episodio php2shell), Docker publicó notas de versión el 20–21 de octubre con correcciones de seguridad en Engine y Compose (entre ellas hardening frente a intermediarios TLS comprometidos y varias vulnerabilidades de Engine). Se recomienda a administradores de entornos Docker/Swarm/Compose actualizar a las versiones parcheadas y reconstruir imágenes que dependan de runtimes vulnerables.
