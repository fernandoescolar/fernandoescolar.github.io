## OpenAI pausa lanzamiento y retrasa modelo por preocupaciones de seguridad
OpenAI ha anunciado la retención o demora de un nuevo modelo (reportado como parte de la familia de modelos más recientes) citando preocupaciones de seguridad internas y resultados inesperados durante pruebas internas. La organización indicó que está revisando comportamientos no previstos de agentes y modelos antes de proceder con un despliegue público mayor, y que determinadas capacidades autonómicas requieren más controles. Esta decisión forma parte de una reacción mayor en la industria sobre riesgos de agentes y despliegues rápidos de modelos de gran escala. Fuente: [AP News](https://apnews.com/article/5afb865b2cddc439efdcf31ebdc406a5)

## Incidentes y errores en Agents API y servicios de OpenAI
En las últimas 24–48 horas se han reportado incidentes y errores elevados en servicios de OpenAI, incluyendo degradaciones que afectaron a ChatGPT, la API y el Agents API en ventanas temporales recientes. OpenAI publicó estados de incidente y actualizaciones en su página de estado durante la investigación y mitigación de errores; el impacto concreto varió por región y por producto (API / Agents). Las comunicaciones oficiales subrayan que parte de la actividad está relacionada con pruebas y ajustes a la plataforma de agentes. Fuente: [OpenAI Status](https://status.openai.com/incidents/35y48hbm)

## Demanda contra OpenAI por fallos relacionados con agentes
Se ha presentado una demanda judicial alegando responsabilidad de OpenAI por la conducta de sus agentes tras incidentes vinculados a comportamientos inesperados. El caso destaca el creciente escrutinio legal y regulatorio sobre compañías que desarrollan agentes autónomos, y subraya riesgos legales emergentes para despliegues sin controles robustos. La noticia ha motivado cobertura amplia en la prensa tecnológica. Fuente: [Axios](https://www.axios.com/2026/09/29/openai-sued-hugging-face-breach)

## Docker Desktop: nueva versión y actualización de seguridad
Docker publicó notas de la versión más reciente de Docker Desktop (lanzamiento reportado el 28 de septiembre) que incluye actualizaciones de componentes (containerd, Buildx, etc.) y correcciones de errores. Además, la documentación de seguridad de Docker lista un parche reciente relacionado con una vulnerabilidad en Docker Desktop (CVE y actualización correspondiente). Se recomienda a los desarrolladores y administradores de máquinas de desarrollo actualizar a la versión más reciente y revisar avisos de seguridad para mitigaciones. Fuente: [Docker Desktop release notes](https://docs.docker.com/desktop/release-notes/) y [Docker security announcements](https://docs.docker.com/security/security-announcements/)

## .NET: actualizaciones de mantenimiento de septiembre (incluye ASP.NET)
Microsoft publicó el resumen de las actualizaciones de mantenimiento de .NET correspondientes a septiembre de 2026, que incluyen parches de seguridad y versiones de servicing para runtime, ASP.NET Core y Entity Framework Core. Los números de servicio y las versiones aplicables se listan en las notas oficiales; administradores de servidores y responsables de aplicaciones deben planificar la aplicación de estos parches para mantener la plataforma segura y soportada. Fuente: [Blog .NET - Servicing updates (septiembre 2026)](https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-september-2026-servicing-updates/)

## Azure: release del SDK (29 de septiembre) y cambios del ecosistema
El equipo de Azure SDK publicó su release de septiembre (29 de septiembre), con actualizaciones y correcciones para librerías cliente en .NET, Java, JavaScript y Python. Estas actualizaciones incluyen mejoras de compatibilidad, correcciones de dependencias y cambios relevantes para desarrolladores que integran servicios Azure en aplicaciones modernas, especialmente en escenarios de IA y datos. Fuente: [Azure SDK Release (septiembre 2026)](https://devblogs.microsoft.com/azure-sdk/azure-sdk-release-september-2026/)

## Microsoft mueve contenido de roadmap a "AI at Work" (Partner Center)
Microsoft informó que, a partir de septiembre de 2026, el contenido de roadmap para Dynamics 365, Power Platform y Dataverse se integrará en un único destino llamado "AI at Work", agrupando asimismo actualizaciones de Copilot, agentes y experiencias relacionadas con AI empresarial. Este cambio centraliza información de lanzamientos y vistas previas para partners y clientes. Fuente: [Partner Center Announcements (septiembre 2026)](https://learn.microsoft.com/partner-center/announcements/2026-september)

## Google Cloud: API Gateway añade streaming para respuestas de LLM (Public Preview)
Las notas de lanzamiento de Google Cloud del 29 de septiembre incluyen una novedad para API Gateway: soporte de streaming para respuestas de LLM (token‑a‑token), disponible en Public Preview. La funcionalidad permite configurar gateways que entreguen respuestas incrementalmente mediante HTTP/2, chunked transfer, SSE o gRPC, útil para integraciones con modelos que devuelven tokens de manera incremental. Fuente: [Google Cloud release notes (29 sep 2026)](https://docs.cloud.google.com/release-notes/)

## QNAP presenta la serie TVS-hx77AX ZFS NAS con NFS over RDMA para cargas AI
QNAP anunció la serie TVS-hx77AX, una familia de NAS ZFS orientada a cargas de trabajo de IA que incluye soporte nativo de NFS sobre RDMA, ranuras U.2 NVMe y opciones de conectividad 10GbE/25GbE. El hardware y el software están pensados para flujos de trabajo que exigen I/O sostenido y baja latencia en entrenamiento o inferencia local de modelos, y apunta tanto a entornos profesionales como a integradores de infra AI on‑prem. Fuente: [QNAP - anuncio oficial (página de noticias en español disponible)](https://www.qnap.com/es-es/news/2026/qnap-presenta-la-serie-tvs-hx77ax-zfs-nas-con-nfs-over-rdma-para-cargas-de-trabajo-de-ia)

## MSI PRO MAX EDGE AI+: mini-PC orientada a inferencia local (anuncio)

MSI publica especificaciones de TOPS combinados y posiciona el equipo para usuarios y equipos que prefieren no depender exclusivamente de la nube para tareas AI.
